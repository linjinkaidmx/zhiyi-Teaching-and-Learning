# 知一 2.0 首页改版规划 · 套用「搜题匠」模板

> 规划日期：2026-09-21 · 规划人：L
> 决策前提（已与用户确认）：
> 1. **保留现有底部 5 Tab 导航**，首页不另加输入框 —— 顶部搜索框兼作 AI 提问入口
> 2. **现有四区块（继续学习 / 今日复习 / 今日课程 / 推荐知识点）全部移除**
> 3. **顶部改为「学习 / 我的」双 Tab + 搜索图标**

---

## 一、改版目标与原则

### 1.1 要套用的

| 套用点 | 说明 |
|---|---|
| **两组横向轮播入口** | 一屏 4 个大卡 + 一屏 5 个小入口，右滑翻页 → 首屏保持清爽，容量翻倍 |
| **顶部 Tab 行** | 「学习 / 我的」+ 右侧搜索，替代现在的"欢迎语 + 副标题"头部 |
| **一个信息/运营位** | 搜题匠放会员促销；知一换成**考试倒计时 / 今日目标进度** |
| **留白** | 按用户要求保持留白，不强行填满 |

### 1.2 不套用的

| 不套用点 | 理由 |
|---|---|
| 高饱和渐变块 | 知一是学术风，用**浅彩底 + 深色图标**（沿用已有课程色系），视觉更克制 |
| 底部常驻输入框 | 与底部「AI对话」Tab 功能重复；改为**顶部搜索框兼提问**（一个框两个用途） |
| 写死的 placeholder | 知一用「搜索错题、知识点，或直接问我」 |
| 商业化促销位 | 知一无商业化，该位置换成对用户有用的学习提醒 |

### 1.3 核心原则

1. **一层直达**：原来要走「更多 → 二级页」的功能，首页轮播里一步可达
2. **首屏不塞满**：一屏只放 4 + 5 = 9 个入口 + 1 个信息位，其余靠横滑承载
3. **重复可控**：轮播（高频入口）与「更多」页（完整目录）允许并存，但**同一功能不在同一屏出现两次**

## 三、槽位内容明细

### ① 顶部：双 Tab + 搜索

| 元素 | 内容 | 交互 |
|---|---|---|
| Tab 1「学习」 | 当前首页全部内容 | 默认选中；选中态用文字加深 + 底部短横线（比搜题匠的纯加粗更明确） |
| Tab 2「我的」 | 现有 `/me` 页 | 点击切换；等价于把现在"藏在更多页里的我的"提到一级 |
| 搜索图标 | 点开全屏搜索层 | 见 3.5"搜索兼提问" |

**为什么用「学习 / 我的」而不是搜题匠的「AI助手 / 我的」**：知一页面内容就是学习流（拍题、错题、自测），叫「学习」准确；「AI助手」会让人以为这里是对话页，重蹈搜题匠命名错位的坑。

### ② 主功能大卡（一屏 4，横滑两页）

**第 1 页**（与底部导航一致，最高频）：

| 卡片 | 色 | 点击去向 |
|---|---|---|
| 拍照搜题 | 蓝 | `/capture` |
| 错题学习 | 紫 | `/wrongbook` |
| 自测练习 | 绿 | `/practice/original` |
| AI 对话 | 橙 | `/chat` |

**第 2 页**（备考工具组）：

| 卡片 | 色 | 点击去向 |
|---|---|---|
| 模拟考试 | 蓝紫 | `/exam` |
| 考前速查 | 青 | `/more?tool=ref` |
| 算法演示 | 靛 | `/more?tool=algo` |
| 代码诊断 | 灰蓝 | `/more?tool=debug` |

**视觉**：浅彩底（课程色 18% 混白）+ 深色图标 + 深色标题，卡片约 150×96，圆角 14px。
**指示器**：底部两个圆点（当前页实心加宽），点击圆点也能翻页。

### ③ 次级入口（一屏 5，横滑两页）

**第 1 页**（学习管理）：

| 入口 | 去向 |
|---|---|
| 课程表 | `/timetable` |
| 考试安排 | `/exams` |
| 我的课程 | `/course` |
| 学习数据 | `/data` |
| 学习记录 | `/records` |

**第 2 页**（扩展）：

| 入口 | 去向 |
|---|---|
| 知一社区 | `/community` |
| 产品介绍 | `/about` |
| 帮助与反馈 | `/help` |
| 账号与同步 | `/me` |

**视觉**：线性图标（与现有 `UiIcon` 一套）+ 12px 文字，无背景块，5 等分。
**滑动提示**：第 5 个入口右侧露出第 6 个的 1/3（"半张卡"提示可滑），比搜题匠只有一条短横线更易发现。

### ④ 信息位（一张卡，随状态变化）

按优先级取第一个**有数据**的展示：

| 优先级 | 类型 | 数据来源 | 文案示例 |
|---|---|---|---|
| 1 | 考试倒计时 | `upcomingExams(1)` | 距「高等数学」期末还有 12 天 · [去复习] |
| 2 | 今日目标进度 | `statsStore` 今日时长/题量 vs 目标 | 今日已学 45 / 60 分钟 · [继续] |
| 3 | 待复习提醒 | `quizPool` 数量 | 有 8 道错题该复习了 · [去复习] |
| 4 | 空态 | —— | 今天还没有学习记录，拍一道题开始吧 · [去拍题] |

**样式**：单张卡片（浅底 + 左侧图标 + 一行主文案 + 右侧文字按钮），高度约 72px。
**设计意图**：这就是搜题匠放促销的位置 —— 知一把商业位换成"最该做的一件事"，既不浪费黄金位，也不打扰用户。

### ⑤ 留白

保持（按用户要求）。首屏内容自然结束在信息位下方，剩余空间留白，不强行填充。

### ⑥ 底部导航

**完全不变**：首页 · 拍题 · 错题学习 · AI对话 · 更多。

### 3.5 搜索框兼提问（替代常驻输入框）

点顶部 🔍 展开全屏搜索层，输入后：

```
输入 → ① 先搜本地
        · 错题本题干（模糊匹配）
        · 知识点标签
        · 课程名（我的课程）
        · 算法名（21 个算法）
      → 有结果：列表展示（点击直达对应页面/条目）
      → 无结果：表单底部出现一行「问 AI：<你的输入>」→ 点击跳 /chat 并自动发送
```

**优点**：一个入口覆盖"找东西"和"问问题"两种诉求，不与底部「AI对话」Tab 重复，也避免搜题匠"输入框只能翻译"的窄化问题。

## 四、被移除的四区块，其功能去哪了

用户决定四区块全部移除。**每项都有替代路径，不会丢功能**：

| 原区块 | 功能含义 | 移除后的替代入口 |
|---|---|---|
| 继续学习 | 上次没讲完的题 | 学习记录（次入口第 1 页）→ 点最后一条继续 |
| 今日复习 | 今天该复习的错题 | 自测练习（大卡第 1 页）—— 进入即按 SRS 出题 |
| 今日课程 | 今天的课 | 课程表（次入口第 1 页）—— 或信息位（④）在"今天有课"时优先展示 |
| 推荐知识点 | AI 推荐的薄弱点 | AI 对话（大卡第 1 页）—— 对话页已有推荐 chips |

**顺带优化建议**：信息位（④）在"今天有课"时优先展示今日课程摘要，等于把"今日课程"以更轻的形式保留了下来。

## 六、实施拆解

| 阶段 | 内容 | 预估改动 |
|---|---|---|
| P1 | 顶部双 Tab + 搜索图标（Tab 切换，搜索层先只做本地搜索） | `HomePage.vue` 头部重构 + 新增搜索层组件 |
| P2 | 主功能大卡轮播（4×2 页，横滑 + 指示器 + 点击跳转） | `HomePage.vue` 新增区块 + CSS scroll-snap |
| P3 | 次级入口轮播（5×2 页） | 同上，复用同一套轮播样式 |
| P4 | 信息位（按优先级选一条展示） | 新增小组件 + 复用 `homeStats`/`statsStore`/`upcomingExams` |
| P5 | 移除四区块 + 清理相关代码与样式 | 删模板与样式；`homeStats.js` 里仅供四区块使用的函数一并清理（`_test_home.mjs` 相应调整） |
| P6 | 回归 + 部署 | 全量 `_test_*.mjs` + CDP 双视口 + 线上验收 |

**技术要点**：
- 轮播用 CSS `scroll-snap`（原生滚动，无第三方库），配合 `IntersectionObserver` 更新指示器
- 浅彩卡色沿用课程色系：`color-mix(in srgb, <色> 18%, var(--surface-unit))`
- 深色主题下同样成立（与课表色块同一套机制，已验证）

**已知风险**：
1. 首页是入口最多的页面，改动面大 → 必须跑完整回归 + 双视口 CDP
2. `_test_home.mjs`（39 项）测的是首页数据计算，四区块移除后部分断言需同步调整
3. 移动端横滑手势与浏览器下拉刷新可能冲突 → 轮播容器需设 `overscroll-behavior-x: contain`

## 九、附录：大卡设计规则（内容你定，这是画布与约束）

### 9.1 位置与容量

- 一屏 **4 张**，可横滑多页（建议最多 2 页 = 8 张）
- 单卡尺寸：约 **62 × 74**（375 宽屏下 4 等分），圆角 12
- 每页底部一个页指示器（当前页实心加宽）

### 9.2 单卡结构（三层，后两层可选）

| 层 | 内容 | 规格 |
|---|---|---|
| 图标 | 线性图标或纯色块 | 26×26，圆角 8，用该卡的功能色 |
| 标题 | **4~6 个字** | 10.5px，该功能色的深色版（如 #254B75） |
| 状态 | 数字 / 倒计时 / 进度 | 8~9px，暖色或次要灰（这是"动作卡"的灵魂） |

### 9.3 配色

从项目**已有的 8 色板**里取（与课表色块同一套语言）：浅彩底 = 该色 18% 混白。

`#3D6FA8` `#6B5B95` `#4A7A63` `#B5722A` `#4A5D8A` `#3D6A7A` `#7A5F3D` `#5A6B7A`

### 9.4 可用的实时状态数据源（放"状态层"用）

| 数据 | 来源 | 示例文案 |
|---|---|---|
| 待复习错题数 | `quizPool`（未掌握或已到期）| 9 道待复习 |
| 最近考试倒计时 | `upcomingExams(1)` | 距期末 12 天 |
| 今日学习进度 | `statsStore` 今日时长/题量 vs 目标 | 45/60 分钟 |
| 连续学习天数 | `statsStore.current` | 连续 6 天 |
| 错题总数 / 掌握率 | 错题本 + `mastered` | 28 题 · 掌握 43% |
| 上次学到哪 | `records` 最近一条 | 接着上次 |
| 最近模拟考分数 | `examStore` | 上次 60 分 |

### 9.5 三条硬约束

1. **不与次入口重复**：次入口固定为管理类（课程表 / 考试安排 / 我的课程 / 学习数据 / 学习记录），大卡不放这五个
2. **同屏不出现两次**：一个功能只能在 ①Hero ②大卡 ③次入口 ④底部导航 中出现一次；语义不同可例外（如导航"错题学习" vs 大卡"复习 9 道错题"）
3. **文案长度**：标题 ≤ 6 字、状态 ≤ 8 字（超了会换行，参考信息位那次）

### 9.6 候选池（供你挑，也可自己想）

- **学习动作**：复习错题 · 错题重做 · 模拟考试 · 拍照搜题 · 自测练习 · 看讲解
- **工具**：考前速查 · 算法演示 · 代码诊断 · 错题导出打印 · 公式速查
- **状态/回顾**：学习数据 · 打卡成就 · 继续学习

### 9.7 已确认的相邻改动

- **拍题升级为 Hero**（占满宽度单独一行），不再挤在四宫格里 → 这样"拍题"不算与底部导航并列重复
- **AI 对话从大卡移除**（底部导航已有，且它是"随时可去"的）
- **右上角 = 提醒铃铛**（已替换搜索图标）
