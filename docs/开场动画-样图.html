点开网站时的入场动画：Logo 开屏 0.95s（图标 → 名称 → 右下角标语依次落位）→ 场景展开 0.85s（云、水面、小船依次驶入）→ 首页内容级联，总时长 约 1.8 秒。动画同时盖住首屏加载的空白期。

播放规则：仅「点开网站」时播（同一标签内刷新与站内跳转不播）；点击或按键立即跳过；系统开启「减少动效」时不播。

五、播放与边界规则

会播：新标签页 / 新会话打开首页（sessionStorage 无标记）
不播：同一标签内刷新、站内跳转与返回、分享深链（如 /q/xxx）、系统开启「减少动效」
跳过：动画期间点击屏幕或敲任意键 → 开屏层 0.15s 淡出，首页元素直接到位
兜底：无论脚本是否正常，开屏层最长 3 秒自动移除
不做：音效（浏览器自动播放策略限制、很多环境静音）；假进度百分比（改用 Logo 呼吸表达加载中）
