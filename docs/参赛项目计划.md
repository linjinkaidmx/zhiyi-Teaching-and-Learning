## 1. 选题

### 1.1 题目
**"知一"—— 基于多模态教学智能体的错题诊断与自适应辅导系统**

对应官方赛题：**方向一 · 多模态教学智能体**（图文素材智能解析、知识点结构化抽取、交互式答疑辅导）

**命名释义**：出自「知一而通万，知其一，举一反三」。
产品逻辑正是"诊断一道错题 → 推荐同类题 → 掌握一类题"，是"举一反三"的产品化表达，
也呼应了官方赛题中"知识点结构化抽取 + 交互式答疑辅导"的要求。

### 1.2 核心价值
- 从"拍照搜答案"升级为"**诊断 + 追踪 + 自适应训练**"的学习闭环
- 不只给答案，定位"**错在哪一步 + 为什么错**"（概念 / 计算 / 审题 / 方法）
- 错题本 + 掌握度 + 间隔重复提醒，让错题真正被消化
- 聚焦**高校场景**（大学课程 + 编程题），是竞品空白区

### 1.3 P0 核心功能（MVP 必做）
1. **多模态录入**：截图粘贴（Ctrl+V）/ 拍照 / 图片上传；拖拽 + 预览
2. **结构化识别**：GLM-4V 理解题目，分离「题目 / 学生作答 / 正确答案」，识别公式（LaTeX）、图形、学科
3. **智能错因诊断**（核心）：定位错在哪一步；错因归类（概念不清 / 计算失误 / 审题偏差 / 方法错误 / 知识盲区）；分步正解
4. **同类题推荐**：按「知识点 + 错因」匹配，难度递进 3-5 题
5. **错题本与追踪**：历史列表、按学科/错因筛选、掌握度标记、复习提醒（间隔重复）、雷达图可视化

### 1.4 P1 增强（有余力做）
- **编程题代码错误诊断**（高校差异化亮点，优先做）
- 批量上传多张错题
- 识别结果手动修正
- 错题导出 PDF / 打印
- 教师端：班级共性错题统计

### 1.5 P2 延伸扩展（加分 / 未来）
- 语音讲解（TTS 朗读解题步骤）
- 几何 / 物理过程动画演示
- AI 学习伙伴多轮追问
- 学情报告（给老师 / 家长）
- 考研专项模式
- 浏览器插件（网页截图直接问诊）
- 对接学校 LMS

### 1.6 不做的（防止 scope creep）
- 用户系统 / 登录（用浏览器 localStorage 代替）
- 云端长期存储（演示用本地 + 服务端临时文件）
- 移动端原生适配（桌面浏览器 + 响应式即可）
- 社交 / 分享功能

## 2. 技术栈

### 2.1 前端
- **构建**：Vite 5.x
- **框架**：Vue 3 (Composition API)
- **UI 组件**：Element Plus
- **HTTP**：axios
- **可视化**：ECharts（掌握度雷达图）
- **粘贴**：Clipboard API（paste 事件读图）
- **图片压缩**：browser-image-compression

### 2.2 后端
- **语言**：Python 3.11+
- **框架**：FastAPI + uvicorn
- **数据校验**：Pydantic v2（强制 JSON schema 校验 LLM 输出）
- **异步**：async/await（LLM 调用不阻塞）

### 2.3 AI 与识别（火山方舟统一网关）2026-09-16 更新

- **平台**：火山引擎方舟（Volcengine Ark），**OpenAI 兼容协议**
  - `base_url = https://ark.cn-beijing.volces.com/api/v3`
  - 一个 API Key 打通视觉 + 文本，无需多平台分别申请
  - 已验证可用模型 **42 个**
- **多模态识别主力**：`doubao-seed-2-1-pro-260915`（豆包最新，支持 image 输入）—— 看图识别题目 / 作答 / 公式 / 图形
- **错因诊断推理**：`deepseek-v4-pro-260813`（DeepSeek V4 Pro）—— 深度推理、分步解析
- **备用模型**：`glm-5-2-260617`（智谱）、`qwen3-32b`（通义）、`doubao-seed-2-1-turbo-260628`
- **结构化输出**：Prompt 约束 JSON + 正则提取 + 后端 Pydantic schema 校验 + 失败重试
- **同类题推荐（MVP）**：预置题库（按知识点 + 错因打标签）+ 标签匹配
- **同类题推荐（P1 可选）**：`doubao-embedding-vision-251215` 向量检索

> **可选链路**：若豆包视觉模型诊断质量足够，可一步到位（看图直接出诊断 JSON）；
> 若推理深度不够，再串联 DeepSeek V4 Pro 做二次推理。先测再定。

### 2.3.1 API Key 安全规范（必须遵守）

- Key **只存 `.env` 文件**，绝不硬编码进代码
- `.gitignore` 必须包含 `.env`（已配置）
- 提交 GitHub 前用 `git status` 检查，确认 `.env` 未被跟踪
- 若 Key 曾在公开对话 / 截图 / 录屏中暴露，**立即去方舟控制台轮换**

### 2.4 部署
- **前端**：LearnBuddy CloudStudio 一键部署（自动得到 https 链接）
- **后端**：CloudStudio 容器 或 腾讯云轻量应用服务器
- **API Key 管理**：前端不暴露 Key，全部后端代理调用

### 2.5 工程
- **仓库**：GitHub
- **版本**：Git + main 分支 + feature branch
- **依赖管理**：前端 pnpm / 后端 pip + requirements.txt
- **代码规范**：前端 ESLint + Prettier / 后端 ruff

## 7. 风险与备案

| 风险 | 备案 |
|---|---|
| GLM-4V 识别公式/手写不准 | 提供手动修正入口；用 DeepSeek 做识别结果二次校验 |
| 错因分类不稳定 | Prompt 加 few-shot 示例 + Pydantic 强制 schema + 失败重试 |
| API 限流 / Key 失效 | DeepSeek + 智谱双 Key 互备；免费额度优先用 flash 模型 |
| 同类题题库不足 | MVP 用 20-30 道精选题 + 标签匹配即可演示 |
| 图片过大超时 | 前端压缩到 ≤2MB，后端限制 10MB |
| 时间不够 | 砍到 3 个：录入、识别、诊断（先砍推荐和错题本可视化） |
