## 七、运维备忘

- 部署：本地构建 → tar → SFTP → `/opt/zhiyi/backend/static`（备份 `static_bak_prev`）→ `systemctl restart zhiyi`
- 后端改动备份：`/opt/zhiyi/backup_<时间戳>/`
- 回滚：前端恢复 `static_bak_prev`；后端恢复对应 backup 目录
- **部署前必做**：先用无头 Chrome 验证（`chrome.exe --headless=new --dump-dom --enable-logging=stderr <url>`），确认零控制台错误再收工
- 本地测试命令：前端 `node _test_*.mjs` / `node _smoke_app.mjs` / `node _smoke_ds.mjs`；后端 `python _test_*.py`
