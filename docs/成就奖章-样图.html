知一 · 成就奖章样图

组合式徽章系统：底座表达稀有度（铜 / 银 / 金 / 紫），图腾表达功能域（搜题 / 错题 / 讲解 / 编程 / 班级 / 考试 / 数据 / 探索）。同一套 SVG 内联绘制，任意尺寸清晰，深浅色自适应。

共 4 档底座 × 8 种图腾，覆盖 43 枚成就；锁定态自动灰度。

一、稀有度阶梯

同一图腾（书页 / 错题域）放在四档底座上，越往上装饰越繁复

普通=六边铜 · 稀有=盾形银 · 史诗=齿边金 · 传说=光环紫（含外环 + 星芒）。传说级在真实页面里光环会缓慢旋转，移动端自动静止。

二、功能域图腾

8 个功能域各有一枚专属图形，与站点图标同一套线条语言

三、奖章墙（部分成就实拍）

挑 18 枚覆盖各稀有度，展示解锁态的实际观感

四、未解锁态

灰度 + 降透明，仍能看出稀有度轮廓与图腾，给人「想拿到」的钩子

五、尺寸阶梯

成就页大卡 / 列表项 / 面板入口 / 角标
96px 详情
64px 卡片
44px 列表
28px 角标

六、深色模式

底座渐变不变，描边与投影加强以保证在深底上有体积感
