错题本主从移动端「列表 → 抽屉弹层」→ 左侧筛选与列表常驻、右侧详情原地展开，切换题目零跳转；右栏补掌握度环、知识点、操作组、同知识点其他错题。
班级三栏移动端单页 Tab 切换 → 班级 / 作业列表 / 批改详情三栏并置；学生提交改为表格（得分、AI 评价、逐份操作一目了然），班级报告与批量操作并排放在下方。
测试双栏答题页 → 居中试卷（题干 + 选项/填空）＋ 右侧答题卡（题号网格标记已答/未答/当前、交卷倒计时、题型分布、一键提交），支持键盘切题。
移动端不动本次只新增桌面形态：移动端继续用现有单列布局与底部/顶部导航；两套布局共用同一套 Design Token 与组件，动态背景在桌面端收敛到 Hero 区，避免全屏动效干扰长时间阅读。

题目 1 / 2 用主定理求 T(n)=2T(n/2)+O(n) 识别置信度高 存入错题本 导出 PDF
AI 讲解追问老师换个讲法举一反三知识点回顾
答案
该算法的时间复杂度为 Θ(n log n)。由主定理第二类情形：a = 2, b = 2，比较 f(n) = O(n) 与 nlogba = n，两者同阶，故 T(n) = Θ(n log n)。
解题步骤
1
写出递归式与三个参数
递归式 T(n) = 2T(n/2) + O(n)，因此 a = 2（子问题个数）、b = 2（规模缩减比）、f(n) = O(n)。
2
计算 nlogba 并与 f(n) 比较
nlog22 = n，与 f(n) = O(n) 同阶 → 属于主定理第二类情形，答案为 Θ(nlogba · log n)。
3
Python 实现（可在线运行）
# 归并排序：T(n) = 2T(n/2) + O(n)
def merge_sort(a):
  if len(a) <= 1: return a
  m = len(a) // 2
  return merge(merge_sort(a[:m]), merge_sort(a[m:]))

主定理速记：三类情形的判定条件
用主定理求 T(n) = 2T(n/2) + O(n) 的时间复杂度 待复习算法分析数据结构
题目
已知归并排序的递归式 T(n) = 2T(n/2) + O(n)，请用主定理求其时间复杂度，并说明属于哪一类情形。
我的作答（批改后自动存档）
由主定理：a=2, b=2，所以 nlogba = n，与 f(n) 同阶，所以是第二类，答案是 O(n log n)。
结论对推导略简
解析 · 3 步
1
读出三个参数：子问题个数 a = 2、规模缩减比 b = 2、额外代价 f(n) = O(n)。
2
计算 nlogba = n1 = n，与 f(n) = Θ(n) 同阶 → 第二类情形。
3
代入第二类公式，得到紧确界 T(n) = Θ(n log n)。
# 第二类：f(n) = Θ(n^(log_b a))
T(n) = Θ(n^(log_b a) · log n) = Θ(n log n)
