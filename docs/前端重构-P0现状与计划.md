### 3.3 设计 token 草案（P1 细化）

- 颜色：`--bg` 深底 / `--surface-1/2/3` / `--border-subtle`（0.06~0.12 alpha）/ `--text-primary/secondary/tertiary` / `--brand` 蓝紫 `#7c5cff` / `--accent-glow`（仅背景氛围）/ 语义色（success/warn/danger/info）
- 圆角：`--r-lg` 16（主卡）/ `--r-md` 12（普通卡）/ `--r-sm` 8（按钮）/ `--r-pill` 999（标签）
- 阴影：`--shadow-soft` 大面积低透明度；`--shadow-card` 极轻
- 间距：4 基数（4/8/12/16/24/32/48/64），容器最大宽 1440（首页）/ 1080（内容页）
- 字阶：h1 28 / h2 22 / h3 18 / body 15 / aux 13 / tag 12；中英文同一无衬线族，代码等宽，公式 KaTeX
- 动效：`--dur-fast` 120ms / `--dur` 200ms / `--dur-slow` 320ms；缓动 `cubic-bezier(.4,0,.2,1)`
- 主题：`html[data-theme="dark"|"light"]`，默认 dark

### 3.4 数据对象与 adapter 映射（不改底层契约）

| 规格对象 | 现有载体 | 映射方式 |
|---|---|---|

| 课程 / 知识点推荐 | 无 | mock 推荐 + 用户确认流程真实实现 |
| 学习记录 / 学习时长 / PracticeAttempt | 无 | 本地存储先行（真实数据结构），后端表就绪后同步 |
| 社区 | 未开发 | 纯介绍页，无 mock 数据 |

**约定**：所有 mock 走 `lib/mock/`，经 `lib/adapter/` 暴露成与真实接口同形的 Promise/流；切换真实后端只改 adapter 内部，UI 不动。UI 中**不允许**出现任何 mock 数据或业务规则硬编码。
