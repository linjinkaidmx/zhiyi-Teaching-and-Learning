# 知一 —— 错题诊断与自适应辅导系统

> **知一而通万 · 知其一，举一反三**
> 诊断一道错题 → 推荐同类题 → 掌握一类题

## 一句话定位
> 从"拍照搜答案"升级为"**错题诊断 + 追踪 + 自适应训练**"的学习闭环系统

## 对应赛题
**方向一 · 多模态教学智能体**（图文素材智能解析、知识点结构化抽取、交互式答疑辅导）

---

## 一、应用场景

高校理工科学生（高数 / 大物 / 编程等课程）在作业、考试、实验中产生错题，
传统做法是手抄错题本或拍照搜题，存在四个真实痛点：

1. **抄题耗时** —— 手抄一道题 3-5 分钟，效率极低
2. **只给答案** —— 搜题 App 给结果，但不知道**为什么错**
3. **做而不看** —— 错题本记完从不复习，缺提醒机制
4. **同类反复错** —— 没有针对性训练，同类型错误一错再错
5. **一个人闭门造车** —— 看不到同伴在哪些知识点上摔跤，换设备错题本就丢了

---

## 二、目标用户

| 用户 | 核心痛点 |
|---|---|
| 高校理工科学生（主力） | 不知错因，同类题反复错 |
| 考研学生 | 刷题量大，错题整理耗时 |
| 高校教师 | 批改负担重，难统计班级共性错误 |

---

## 三、核心功能

### 1. 单入口三模式自动路由（核心创新）

用户**只管拍一张图**，系统在一次调用内自动判断题图类型并选择分析策略，无需手动切换：

| 模式 | 触发条件 | 系统返回 |
|---|---|---|
| **错因诊断** `diagnose` | 图中既有题目又有作答/演算/批改痕迹 | 错误步骤定位 + 5 类错因归类 + 分步正解 |
| **题目解答** `solve` | 图中只有题目、无作答痕迹 | 完整分步解析 + 解题关键 + 知识点讲解 |
| **无效识别** `invalid` | 无可识别的题目内容 | 友好提示，引导重新拍摄 |

> 传统工具要求用户先选"我要搜题"还是"我要批改"，知一**把选择题消灭掉**。

### 2. 三个入口统一入库 · 题面可校对

任何来源的题目，都能转成**干净的文字**进练习本：

| 入口 | source | 是否带错因 |
|---|---|---|
| 拍错题 → 错因诊断 | `diagnose` | 带错因与出错步骤 |
| 拍题 → 题目解答 | `solve` | 无错因，作为练习收藏 |
| 同类题推荐里主动加入 | `bank` | 无错因 |

入库前弹出**题面确认框**，把 AI 提取的题干、知识点、正确答案摊开来给用户校对再存——
公式里的符号和下标最容易被多模态模型漏掉，这一步让「转成文字」真正可信，而不是静默存一条脏数据。

### 3. 自测闭环（把 K12 的"错题本"变成真正会让人学会的产品）

自测的核心不是界面，而是**闭合了学习回路**：

```
抽题（答案隐去） → 作答 → 批改 → 状态流转 → 回到抽题队列
```

- **组卷**：优先「从未测过 > 上次答错 > 最久没测」，题量可选 5 / 10 / 全部
- **答案隐去**：只显示题干，`correct_answer` / `solution_steps` / `error_analysis` 全部屏蔽；
  卡壳时可选「给我知识点提示」，比直接偷看答案温和
- **双重批改**：默认自查对照（秒出，零延迟）；另有「让 AI 帮我批改」按钮，
  由模型判定「正确 / 部分正确 / 错误」并指出最关键的一处问题，用户可改判
- **状态流转**：答对累计 streak，**连续 2 次自动标记「已掌握」**；
  答错 streak 归零，退回队列下次优先重测——掌握度雷达图与自测正确率同步刷新

### 4. 其余功能

1. **多模态录入** —— Ctrl+V 粘贴截图 / 拍照 / 上传，3 秒上手
2. **结构化识别** —— 多模态模型理解题目，分离「题目 / 作答 / 答案」，识别公式与图形
3. **知识拓展** —— 每种模式都输出「解题关键 + 知识点系统讲解 + 2-4 个延伸知识点/常见题型」
4. **同类题推荐** —— 按「知识点 + 错因」双维度匹配，难度递进
5. **练习本与追踪** —— 掌握度雷达图 + 自测正确率 + 薄弱知识点定位

### 5. 学习社区（把「个人闭环」升级为「群体闭环」）

一个人的错题只有几种错法，**一群人的错题才能暴露一类人的共性盲区**。
社区模块由三块拼成，共用同一套账号：

#### (1) 账号体系 —— 游客也能用，登录也不丢

| 状态 | 数据存放 | 说明 |
|---|---|---|
| 游客 | 浏览器本地 `zhiyi_error_book` | 不注册也能拍题、收录、自测，零门槛试用 |
| 已登录 | 云端 SQLite + 本地缓存 `zhiyi_error_book_account` | 错题自动同步上云，换设备、清缓存都不丢 |

两个空间**完全隔离、互不覆盖**：登录时切换到干净的账号空间并全量拉取云端数据，
登出回到原本的游客视图，旧数据原样保留。任何一侧的增删改都不会污染另一侧。

配套的账号安全能力：注册 / 登录 / 改密、**备份码找回**（注册时下发 16 位备份码，用于忘记密码自助重置）、
异地登录后旧设备凭证即时失效。

#### (2) 论坛 —— 一键把练习本里的错题变成帖子

- 练习本每行都有「分享」按钮，**一键把错题原文（含 LaTeX 公式）发到论坛**，不用手抄第二遍
- 帖子分「普通讨论」与「错题求助」两类，后者强制校验题干非空，保证帖子质量
- 支持**点赞**（可取消，同一人不重复计）与**评论**（支持一层回复，形成轻量讨论串）
- 学科筛选 + 分页，帖子流按时间倒序
- 别人分享的错题可**一键保存回自己的练习本**，直接进自测队列

#### (3) 学习小组 —— 凭 6 位码组队，共建错题池

- 组长创建小组后拿到 **6 位小组码**（字符集去掉 `0/O`、`1/I/L` 等易混淆字符，口述/手抄都不易错）
- 成员凭码加入，**主动**选择把哪些错题共享到组内——默认不共享，尊重隐私
- 组内「**学习榜**」实时展示每位成员的练习量、自测次数与正确率，
  让"互相卷"变成可视化的正向反馈
- 组长可解散小组，成员可自由退出（组长须先转让或解散，防小组失主）

> **为什么是「主动共享」而不是「自动全共享」**：错题带有挫败感，属于半私密数据。
> 强制公开会让用户不敢记真实错误，反而破坏数据真实性。主动共享既保住隐私，也保住数据质量。

## 四、技术亮点

- **单模型多模式自动路由**：一次 API 调用同时完成「题图类型判断 + 结构化分析」，模式由模型自主判定并经后端规范化兜底（`_normalize`），非法值自动降级
- **多模态深度理解**：非简单 OCR，能理解图形、公式、手写与作答痕迹
- **双向 JSON 契约**：Prompt 强约束 JSON 输出 + 正则兜底提取 + Pydantic v2 字段级校验，全字段默认值保证任一模式下接口契约不破裂
- **双阶段判分**：自测批改既支持本地秒出的自查对照，也可调用 `/api/judge` 由模型做语义级判定——能识别「书写格式不同但数学等价」（C₁ vs C1、e^x vs exp(x)），并给出破坏性的问题定位
- **轻量间隔重复**：`lastQuizAt` / `lastQuizCorrect` / `streak` 三字段即可驱动「从未测过 > 上次答错 > 最久没测」的优先级队列，不引入任何推荐系统复杂度
- **自适应推荐**：按错因而非仅知识点推题（如"总计算失误" → 推细心训练题）
- **前后端一体化同源部署**：单 uvicorn 进程同时提供静态页与 API，根除 HTTPS 混合内容拦截，免 Nginx / 域名 / 证书
- **工程完整**：JSON schema 校验、异常分级处理、systemd 守护、准确率测试报告

**社区与安全（新增）**

- **无状态会话 token**：自定义三段凭证 `base64url(userId).过期时间.HMAC(userId::authNonce::exp)`，
  服务端不存会话表即可 30 天免登录；用户改密时轮换 `authNonce`，**所有已签发 token 即时失效**，兼顾性能与吊销能力
- **密码安全**：`pbkdf2_hmac-sha256` **30 万轮**迭代 + 每用户独立随机盐；登录失败按「昵称 + IP」限流
  （15 分钟 5 次），杜绝暴力破解；备份码找回做大小写归一化，避免手抄小写造成二次丢失
- **混合存储模型**：`records` 表采用「固定索引列（用户/学科/题干/知识点/错因/掌握状态）+ JSON 明细列」，
  既能按高频维度建索引查询，又能**无损还原任意结构的错题对象**，后续加字段无需迁移表结构
- **json_extract 实时聚合**：学习榜、练习量、正确率不落冗余计数器，
  直接 `json_extract(data, '$.quizCount')` 现算，根除「计数器与明细不一致」这类经典脏数据
- **双数据空间 + 写后同步钩子**：本地写入成功即刻返回 UI，云端同步失败静默降级（不打断学习流程）；
  登录重建缓存时的清空操作**刻意不触发同步**，避免 "清空 → 同步删除 → 云端数据被抹" 的自毁循环
- **零新增依赖**：账号、论坛、小组全部基于 Python 标准库（`hashlib` / `hmac` / `secrets` / `sqlite3`）实现，
  SQLite 开启 WAL + 忙等超时 + **线程本地连接**，单文件数据库也能安全扛住并发写

## 五、差异化优势

| 对比维度 | 传统搜题 App | 知一 |
|---|---|---|
| 使用门槛 | 先选"搜题"还是"批改" | **拍一张图，自动判断** |
| 是否给答案 | 给答案 | 给解析 + 错因（不给裸答案） |
| 错因诊断 | 无 | 5 类归类 + 步骤定位 |
| 知识讲解 | 多为碎片答案 | 解题关键 + 系统讲解 + 延伸学习 |
| 题面质量 | OCR 结果不可校对 | **入库前可编辑校对** |
| 事后检验 | 无，看完就走 | **自测：答案隐去重做 + 双重批改** |
| 学习效果 | 不可量化 | 掌握度 + 自测正确率 + 薄弱点定位 |
| 推荐逻辑 | 同知识点 | 知识点 + 错因双维度 |
| 覆盖场景 | K12 为主 | **大学课程 + 编程题** |
| 使用门槛（注册） | 强制注册才能用 | **游客零门槛可用，想留存再注册** |
| 数据留存 | 本地即丢 / 强绑云账号 | **游客本地 + 账号云端双空间，互不污染** |
| 社交属性 | 无，纯单机工具 | **论坛一键分享错题 + 评论讨论** |
| 群体学习 | 无 | **6 位码学习小组 + 组内错题池 + 学习榜** |

## 六、应用价值

- **学生**：从"知道答案"到"知道为什么错"，让错题真正被消化
- **教师**：可统计班级共性错误，反哺教学改进
- **合规**：定位学习辅助诊断工具而非搜题代做，规避 K12 监管风险

- 全国高校在校生 **4000 万+**，理工科约 40% → **1600 万+**
- 考研报名 **400 万+ / 年**
- 现有错题 / 搜题工具主要覆盖 K12，**高校场景供给稀缺**
