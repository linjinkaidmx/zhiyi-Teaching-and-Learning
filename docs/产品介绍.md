# 知一 —— 错题诊断与自适应辅导系统

> **知一而通万 · 知其一，举一反三**
> 诊断一道错题 → 推荐同类题 → 掌握一类题

## 一句话定位
> 从"拍照搜答案"升级为"**错题诊断 + 追踪 + 自适应训练**"的学习闭环系统

## 对应赛题
**方向一 · 多模态教学智能体**（图文素材智能解析、知识点结构化抽取、交互式答疑辅导）

---

## 一、应用场景

高校理工科学生（高数 / 大物 / 编程等课程）在作业、考试、实验中产生错题，
传统做法是手抄错题本或拍照搜题，存在四个真实痛点：

1. **抄题耗时** —— 手抄一道题 3-5 分钟，效率极低
2. **只给答案** —— 搜题 App 给结果，但不知道**为什么错**
3. **做而不看** —— 错题本记完从不复习，缺提醒机制
4. **同类反复错** —— 没有针对性训练，同类型错误一错再错

---

## 二、目标用户

| 用户 | 核心痛点 |
|---|---|
| 高校理工科学生（主力） | 不知错因，同类题反复错 |
| 考研学生 | 刷题量大，错题整理耗时 |
| 高校教师 | 批改负担重，难统计班级共性错误 |

---

## 三、核心功能

1. **多模态录入** —— Ctrl+V 粘贴截图 / 拍照 / 上传，3 秒上手
2. **结构化识别** —— 多模态模型理解题目，分离「题目 / 作答 / 答案」，识别公式与图形
3. **智能错因诊断** —— 定位错误步骤 + 5 类错因归类（概念 / 计算 / 审题 / 方法 / 盲区）+ 分步正解
4. **同类题推荐** —— 按「知识点 + 错因」双维度匹配，难度递进
5. **错题本与追踪** —— 掌握度雷达图 + 间隔重复复习提醒

---

## 四、技术亮点

- **多模态深度理解**：非简单 OCR，能理解图形、公式、手写与作答痕迹
- **错因诊断模型**：5 类错因分类 + 分步定位，输出结构化 JSON（schema 校验 + 重试）
- **自适应推荐**：按错因而非仅知识点推题（如"总计算失误" → 推细心训练题）
- **工程完整**：前后端分离、JSON schema 校验、异常处理、准确率测试报告

---

## 五、差异化优势

| 对比维度 | 传统搜题 App | 知一 |
|---|---|---|
| 是否给答案 | 给答案 | 给解析 + 错因（不给裸答案） |
| 错因诊断 | 无 | 5 类归类 + 步骤定位 |
| 错题追踪 | 无 | 错题本 + 掌握度 + 复习提醒 |
| 推荐逻辑 | 同知识点 | 知识点 + 错因双维度 |
| 覆盖场景 | K12 为主 | **大学课程 + 编程题** |

---

## 六、应用价值

- **学生**：从"知道答案"到"知道为什么错"，让错题真正被消化
- **教师**：可统计班级共性错误，反哺教学改进
- **合规**：定位学习辅助诊断工具而非搜题代做，规避 K12 监管风险

---

## 七、市场空间

- 全国高校在校生 **4000 万+**，理工科约 40% → **1600 万+**
- 考研报名 **400 万+ / 年**
- 现有错题 / 搜题工具主要覆盖 K12，**高校场景供给稀缺**
