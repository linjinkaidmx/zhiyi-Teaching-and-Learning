# 参赛材料 · 给 Demo 视频加配音与背景音乐

> **现状**：`demo-video.mp4` 是**纯画面**（无音轨），`bgm.wav` 是配套的背景音乐。
> **为什么不在视频里直接混**：我在 headless 浏览器里试了音频轨混流，3 秒测试正常，但 182 秒长录制只产出 50KB 数据（编码器异常）；本机又没有 ffmpeg（pip 源不可达、npm 安装被权限拦），`Add-Type`/COM 调系统 TTS 也被安全策略拦截。
> **所以改成分开交付**——而且这样**音质更好、你还能换成自己的声音**。

---

## 推荐做法：剪映（免费，10 分钟，还能一键生成配音）

### 第 1 步：导入

1. 下载 **剪映**（专业版 PC / 手机版都行）：`https://www.capcut.cn`
2. 新建项目 → 导入 **`参赛素材/demo-video.mp4`** → 拖到时间线

### 第 2 步：加背景音乐

1. 把 **`参赛素材/bgm.wav`** 拖到时间线的**音频轨**（在视频轨下方）
2. 选中它 → 右侧调**音量到 12~18%**（背景音乐要"在"，但不能盖过人声）
3. 若时长不匹配：剪映里拖音频边缘裁一下即可（音乐是 182 秒，与视频等长）

### 第 3 步：加配音（已备好 SRT，可一键生成）

> 我已经生成了 **`参赛素材/demo-video.srt`**（21 条字幕，时间轴与画面严格对齐）。
> 剪映导入后**全选 → 朗读**，即可一键生成整片配音——**不需要逐段粘贴文本**。

**做法 A：导入 SRT + 批量朗读（推荐，约 3 分钟）**

1. 把 `demo-video.mp4` 拖到时间线
2. 顶部菜单 **文本 → 智能字幕 / 本地字幕 → 导入字幕文件**（不同版本叫法略不同，找"导入字幕"）
3. 选择 **`参赛素材/demo-video.srt`** → 21 条字幕会自动铺到时间轴上（位置与画面一一对应）
4. **框选全部字幕**（或 Ctrl+A）→ 右侧面板点 **朗读** → 选一个音色
   - 建议"**知性女声**"或"**纪录片男声**"这类，避免太甜或卡通的
5. 生成后音频会自动对齐到对应时间段；把配音音量设为 **100%**
6. 顺便**可以选择保留 SRT 字幕轨**（比画面里烧录的字幕更灵活，后期能开关）—— 也可以直接关闭，因为画面里已经有字幕了

**做法 B：自己念（效果最好，评委听得出诚意）**

1. 打开 `参赛素材/demo-video-旁白台词.txt`（21 行，按顺序念）
2. 用手机或电脑录音，按 SRT 里的时间点对齐
3. 把录音拖进剪映，音量 100%

### 第 4 步：导出

- 分辨率 **1080p**，帧率 **30fps**，码率选"**推荐**"或更高
- 格式 MP4
- 导出后**完整看一遍**：确认配音与画面同步、音乐不抢戏

## 如果你不想用剪映

- **PowerPoint**：插入视频 → 再插入音频（`bgm.wav`）设为"跨幻灯片播放"→ 录音旁白 → 导出为视频 ✓ 也能做到
- **必剪 / 快剪辑 / 喵影**：操作与剪映类似
- **只想加音乐不想录旁白**：直接把 `bgm.wav` 与视频合并也行——有音乐的视频比完全静音好，但**字幕已经在传达信息**，所以配音不是必需项

## 关于音乐

`bgm.wav`（182 秒，44.1kHz 立体声）是**程序合成的分解和弦**（C–Am–F–G 循环，柔和的三角波+正弦波，低通滤波），特点：

- **无版权风险**（不是任何现成曲子）
- 音量本来就很轻（渲染时已压到很低），导入后建议再调到 12~18%
- 不喜欢的话：剪映音乐库里挑一首"轻音乐/钢琴"类也可以，**注意选可商用的**
