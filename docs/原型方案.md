# 知一 · 原型方案（5 页线框说明）

> 给产品同学：照着这份描述在 **墨刀 / 即时设计 / Figma** 画出 5 页原型。
> 画布尺寸建议：1440 × 900（桌面 Web）

---

## 全局规范

### 配色
| 用途 | 色值 |
|---|---|
| 主色（品牌紫） | #534AB7 |
| 主色浅底 | #EEEDFE |
| 错因警示红 | #E24B4A |
| 正确绿 | #639922 |
| 文字主 | #2C2C2A |
| 文字次 | #5F5E5A |
| 边框 | #D3D1C7 |
| 背景 | #FFFFFF / #F1EFE8 |

### 字体
标题 18-24px / 正文 14px / 辅助 12px，中文用思源黑体或系统默认

### 全局 Header（所有页面共用）
- 左：Logo「知一」+ 副标「知一而通万 · 举一反三」
- 中：导航（首页 / 错题本 / 关于）
- 右：帮助图标

---

## Page 1 · 录入页（首页）

### 布局
- 顶部：全局 Header
- 中央（60% 宽）：**主录入区**
- 下方：**三种输入方式卡片**（3 列）
- 底部：**最近诊断记录**（横向 3 条）

### 主录入区（大虚线框）
- 虚线边框 2px，圆角 16px，高 320px，hover 时边框变主色
- 内部居中：
  - 上传图标（48px）
  - 主文案 20px：「粘贴或拖入错题图片」
  - 副文案 14px 灰：「支持 Ctrl+V 粘贴截图 / JPG / PNG，单张 ≤ 10MB」
  - 按钮「选择文件」（主色填充）

### 三种输入方式卡片（3 列）
1. **粘贴截图** — 图标 + 「Ctrl+V 粘贴」
2. **拍照上传** — 图标 + 「调用摄像头」
3. **选择文件** — 图标 + 「从本地选择」

### 最近诊断记录（底部）
标题「最近诊断」+ 3 张卡片横排（缩略图 + 知识点名 + 错因标签 + 时间）

### 交互
| 操作 | 反馈 |
|---|---|
| 页面任意处 Ctrl+V | 读剪贴板图片 → 跳 Page 2 |
| 拖拽图片到虚线框 | 框变主色高亮 → 松手跳 Page 2 |
| 点「选择文件」 | 开文件选择器 → 选中跳 Page 2 |
| 点最近记录卡片 | 跳 Page 3（该次诊断结果） |

### 状态
- 空状态（无历史）：隐藏「最近诊断」模块
- 错误（非图片 / 超 10MB）：Toast「请上传 JPG/PNG 图片，且小于 10MB」

## Page 2 · 识别进行中

### 布局
中央卡片（宽 480px，居中）：
- 顶部：刚上传图片缩略（高 160px，object-fit: contain）
- 中部：进度条 + 百分比数字
- 下部：**三步状态流**
- 底部：「取消」文字按钮

### 三步状态流（每项一行）
| 步骤 | 文案 | 状态样式 |
|---|---|---|
| 1 | 正在理解题目 → 识别题型与学科 | 完成：绿色勾 + 文字变灰 |
| 2 | 提取你的作答 → 定位错误步骤 | 进行中：主色旋转图标 + 文字主色 |
| 3 | 比对并生成诊断 → 归类错因 | 等待：灰色空心圆 + 文字浅灰 |

### 交互
- 进入自动开始，每步 1-3 秒，总计 3-8 秒，完成自动跳 Page 3
- 点「取消」：中止，返回 Page 1

### 状态
- 超时（>15s）：显示「识别较慢，仍在努力…」并继续等待
- 失败：错误页「识别失败，请重试」+「重新上传」按钮

---

## Page 3 · 诊断结果页（核心页）

### 布局（左右分栏 40% : 60%）

#### 左栏：原题图片
图片展示区（可点击放大 / 滚轮缩放），下方小字「原图 · 点击放大」

#### 右栏：诊断面板

**顶部标签区**
- 学科标签（如「高等数学」，主色浅底）
- 知识点标签（如「二阶常系数微分方程」，1-2 个）
- 错因标签（**红色**，如「概念理解错误」）

**Tab 切换（3 个）**
1. 「诊断摘要」（默认）
2. 「你的作答」
3. 「分步解析」

**Tab 1 · 诊断摘要**
- 错因标题（红色 18px）：「概念理解错误 — 混淆了齐次解与特解」
- 错误定位：「错误出现在第 3 步」+ 该步高亮
- 一句话正解：「应先求对应齐次方程的通解，再叠加特解」
- 「查看完整解析」链接 → 切到 Tab 3

**Tab 2 · 你的作答**
展示识别出的学生作答（文本 / 公式），错误步骤用红色波浪下划线标出

**Tab 3 · 分步解析**
编号步骤列表（1. 2. 3. …），每步含说明 + 公式（LaTeX 渲染）；
错误步骤用红框标出 + 批注「你在这里出错了」

**底部操作按钮**
- 「加入错题本」（主色填充）
- 「追问 AI」（描边）→ 打开对话抽屉
- 「看同类题」（描边）→ 跳 Page 4

### 交互
| 操作 | 反馈 |
|---|---|
| 点错因标签 | 展开该错因详细解释卡片 |
| 点「追问 AI」 | 右侧滑出对话抽屉，可多轮提问 |
| 点「加入错题本」 | Toast「已加入，已安排复习计划」+ 按钮变「已加入」 |
| 点「看同类题」 | 跳 Page 4 |

### 状态
识别不确定：顶部黄色提示条「识别结果可能不准，可手动修正」+「修正」按钮

---

## Page 4 · 知识点与同类题

### 布局
- 上部：**知识点卡片**（1-2 个）
- 中部：**同类题推荐**（3-5 道）
- 底部：「返回诊断结果」链接

#### 知识点卡片
- 知识点名称（16px）
- 掌握度进度条（0-100%）
- 统计：「已错 3 次 · 上次错误 2 天前」
- 标签：掌握状态（未掌握 / 复习中 / 已掌握）

#### 同类题推荐（卡片列表，纵向）
每题一张卡片：
- 左：难度标签（基础 / 进阶 / 挑战）
- 中：题干摘要（2 行截断）
- 右：「练习」按钮

> 推荐逻辑（给评委看）：按「知识点 + 错因」双维度匹配，难度递进

### 交互
点「练习」→ 内联展开题目详情；难度顺序：基础 → 进阶 → 挑战

---

## Page 5 · 错题本 / 我的

### 布局
- 第一行：**统计卡片**（4 个）
- 第二行：左「掌握度雷达图」+ 右「今日复习计划」
- 下部：**错题列表**（可筛选）

#### 统计卡片（4 个横排）
| 卡片 | 内容 |
|---|---|
| 总错题 | 数字 + 「道」 |
| 待复习 | 数字（主色） |
| 已掌握 | 数字（绿色） |
| 本周新增 | 数字 |

#### 掌握度雷达图（ECharts）
5-6 个维度（各知识点），0-100% 掌握度

#### 今日复习计划
「今日待复习 N 题」+「开始复习」按钮 + 间隔重复说明小字

#### 错题列表
- 筛选栏：学科下拉 / 错因下拉 / 掌握状态下拉 / 搜索框
- 表格行：缩略图 + 知识点 + 错因标签 + 加入时间 + 操作（复习 / 标记掌握 / 删除）

### 交互
- 点行 → 跳 Page 3（该错题诊断详情）
- 筛选实时过滤
- 「标记掌握」→ 该行变灰 + 统计更新

### 状态
空状态：「还没有错题，去上传第一道吧」+ 按钮

---

## 页面流程

```
Page 1（录入）
  → Page 2（识别中）
  → Page 3（诊断结果）核心
       ├→ Page 4（知识点 + 同类题）
       ├→ 追问 AI（抽屉）
       └→ Page 5（错题本）
Page 5 → Page 3（点击某条错题）
```
