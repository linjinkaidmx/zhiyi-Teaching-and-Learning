## 录制与呈现规范

| 项 | 规范 |
|---|---|
| 分辨率 / 帧率 | 1920×1080 / 30fps |
| 字幕 | 屏幕下方居中，字号 40px，白字加深色半透明底条（可读性优先）；每屏最多两行 |
| 图片处理 | 统一加 1px 浅描边 + 圆角 12px；不放超过两个元素 |
| 配色 | 主色 `#6F57F0`，深底 `#1B2334`，成功绿 `#1D9E75`（与 PPT 保持一致） |
| 时长控制 | 总长 ≤ 3:05（官方要求 3 分钟，略超可接受） |
| 不要做的事 | 不放真人出镜（非必需）；不加背景音乐（版权风险且无必要）；不加夸张动效 |

## 如果之后想加旁白（可选）

视频本身是"字幕 + 画面"，不加旁白也完整。若想加真人旁白：

1. **录屏方式**：用系统自带 `Win + G`（Xbox Game Bar）或 PowerPoint 录屏，播放本视频 → 同时念下面的词
2. **旁白稿**（按镜头，约 3 分钟，语速自然）：

> （镜头1）这是知一 2.0，一个面向大学理工科的 AI 学习平台。
> （镜头2）它解决三件事：课后问不到人、错题不会重做、老师批完沉淀不出学情。
> （镜头3）拍照或者直接输入题目，AI 会流式地讲解，可以追问，也可以让它换个讲法。
> （镜头4）错题会自动沉淀，并按遗忘曲线安排复习；对薄弱知识点，可以一键生成同类题来练。
> （镜头5）老师这边，学生拍照提交作业后，一键发起并发批改，几十份作业不用守着；成绩可以导出，报告能打印。
