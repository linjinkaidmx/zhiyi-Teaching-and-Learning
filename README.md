# 知一 2.0

> 面向大学理工科的 **AI 拍题讲解 + 错题自测 + 班级教学** 平台
> 拍照搜题 → 流式讲解 → 错题沉淀 → 间隔复习 → 学情反哺，并把这条链路延伸到班级教学与批改

在线体验：`http://193.112.28.51:3300`（移动端与桌面端均已适配）

---

## 它解决什么问题

大学生做题时遇到的三个断点：

1. **问不到人**——课后没人讲，搜题工具只给答案不给过程
2. **错了不改**——错题散落在纸上，不会回头重做，也没有"什么时候该复习"的机制
3. **老师看不见**——班级作业收上来只能逐份手工批，批完也沉淀不出学情

知一把这三件事做成闭环：**讲透一道题 → 沉淀成错题 → 按遗忘曲线复练 → 把班级数据反哺教学**。

## 功能

### 学习主链路
- **拍照 / 传图 / 文字搜题**：多图提交，自动压缩、空白与模糊检测、长图切段
- **流式 AI 讲解**：SSE 逐字输出，支持**追问**与**换个讲法**（同一题多种讲法对比）
- **错题本**：「一键存错题」，保留讲解与追问，可补充知识点
- **自测（SRS 间隔复习）**：按遗忘曲线排期，连续答对 2 次判为掌握
- **学情看板**：掌握度、错误率、趋势，**薄弱知识点可直接「练一组」**（AI 生成同类题 → 作答 → 判分 → 答错自动入库）

### 班级教学（教师端）
- 老师自助声明认证 → 建班（邀请码）→ 布置作业
- 学生**拍照提交**（可重交覆盖）→ **并发 AI 批改**（可后台跑，关掉页面也继续）
- **逐题判定 + 分数 + 评语**、班级报告、**成绩单导出（CSV）**、报告打印（PDF）
- **群聊实时推送**（SSE，2~3 秒送达）、成员管理、班级笔记

### 考试
- 模拟考试：组卷 → 计时作答 → 选择题本地判 + 主观题 AI 判 → 复盘
- 班级测试：答题卡、排名、错题自动沉淀

### 学习工具
- 代码编辑器 + **在线判题**、代码诊断（贴报错定位问题）
- **算法演示**（15 个算法 × 4 种语言分步动画）、题库↔演示联动
- 考前速查（97 条公式 + 21 个模板 + 复杂度表）、题库秒答

### 成长与运营
- 每日打卡（含护盾机制）、**51 枚成就**（4 档稀有度 + 分级庆祝动画）
- 学习数据、**成长报告**（三档时间范围，可打印）
- 课程表、考试安排、学习记录、知一社区（发帖/评论/点赞/小组）

## 技术方案

```
┌─────────────────────────────────────────────┐
│  Vue 3 + Vite（单页应用，26 页面 / 30 个 UI 组件）  │
│  · 路由级分包 · MathText 公式渲染（三级降级）        │
│  · 深浅色主题 · 移动端适配 · 动态背景（纯 CSS+SVG）  │
└──────────────────┬──────────────────────────┘
                   │ 同源（FastAPI 静态托管 + 缓存策略）
┌──────────────────▼──────────────────────────┐
│  FastAPI 单进程 · 73 个接口 · SQLite（25 张表）    │
│  · 识别：方舟 doubao（多模态）                    │
│  · 讲解：deepseek-reasoner（SSE 流式）           │
│  · 批改：按调用位可配（含并发 3 的任务化批改）        │
│  · 题库：归一化 + 数字指纹的跨写法命中              │
└─────────────────────────────────────────────┘
```

**关键设计**
- **模型按调用位配置**：识别/讲解/判分各用各的模型与 Key，可按成本与质量单独调整；未配置 Key 时自动走内置 Mock，功能不中断
- **批改任务化**：`grade-start` 提交任务 → 服务端线程池并发 3 跑完 → 前端轮询进度，老师可离开页面；单份失败不影响其它份
- **题库跨写法命中**：归一化处理标点、题号、LaTeX 命令与 Unicode 数学符号差异（`√`↔`\sqrt`、`x²`↔`x^2`），数字指纹拦"差一个数字"的误匹配
- **公式渲染三级降级**：结构化字段走 MathText → 失败退 `latexToPlain` → 保证任何情况下页面上不出现裸 `$`
- **纸面信息利用**：转录阶段标注 `{涂改}` / `{空白}`，让判分能识别跳步与涂改

## 目录结构

```

  main.py         接口层（73 个接口）
  service.py      模型调用封装（识别/讲解/判分、SSE、图片预处理）
  db.py           SQLite 数据层（25 张表）
  bank.py         题库命中与回填
  auth.py         账号与令牌
  _test_*.py      后端离线回归
frontend/         Vue 3 前端
  src/pages/      26 个页面
  src/components/ 业务组件（讲解面板、错题本、班级、考试、工具…）
  src/ui/         30 个自研 UI 组件
  src/lib/        纯逻辑模块（可离线断言：SRS、统计、错误分类、按需加载…）
  _qa_*.mjs       端到端验证脚本（CDP 驱动）
  _test_*.mjs     离线回归
docs/             设计与约定文档
```

## 本地运行

```bash
# 后端（Python 3.13）
cd backend
pip install -r requirements.txt
cp .env.example .env          # 填入模型 Key（不填也能跑，走 Mock）
uvicorn main:app --port 8000

# 前端（Node 22）
cd frontend
npm install
npm run dev                   # 默认代理到本地 8000
```

生产：前端 `npm run build` 后由 FastAPI 托管静态资源，单进程即可对外服务（详见 `docs/` 内部署与缓存约定）。

## 安全约定

- **密钥不落盘**：模型 Key 与服务器凭据一律经环境变量注入；`.env`、本地数据库、测试账号 token 均不入库
- 图片与错题数据存于自有服务器 SQLite；账号密码加盐哈希存储
- 学生提交的作业图仅班级老师与本人可见
