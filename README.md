# 知一 · 错题诊断与自适应辅导系统

> **知一而通万 · 知其一，举一反三**
> 诊断一道错题 → 推荐同类题 → 掌握一类题

## 项目简介

「知一」是面向**高校理工科学生**的错题诊断与自适应辅导系统，
对应赛题方向一「多模态教学智能体」。

传统拍照搜题只给答案、不做诊断；手抄错题本耗时且从不复习。
「知一」用多模态大模型看懂错题，**定位错在哪一步、归类为什么错**，
再推荐同类题、安排复习计划，形成"诊断 → 追踪 → 自适应训练"的学习闭环。

### 核心理念

> 从"拍照搜答案"升级为"**错题诊断 + 追踪 + 自适应训练**"。

## 核心功能

| 功能 | 说明 |
|---|---|
| 多模态录入 | Ctrl+V 粘贴截图 / 拍照 / 上传，3 秒上手 |
| 结构化识别 | 多模态模型理解题目，分离「题目 / 作答 / 答案」，识别公式与图形 |
| 智能错因诊断 | 定位错误步骤 + 五类错因归类 + 分步正解 |
| 同类题推荐 | 按「知识点 + 错因」双维度匹配，难度递进 |
| 错题本与追踪 | 掌握度雷达图 + 间隔重复复习提醒 |

### 五类错因体系

`概念理解错误` · `计算失误` · `审题偏差` · `方法错误` · `知识盲区`

## 技术架构

```
用户粘贴错题图片
        ↓
  Vue3 前端（Vite + Element Plus）
        ↓  POST /api/diagnose (multipart)
  FastAPI 后端
        ↓  base64 编码
  火山方舟 · 豆包多模态模型 (doubao-seed-2-1-pro-260915)
        ↓  结构化 JSON
  Pydantic 校验 → 返回诊断结果
```

**为什么选火山方舟**：一个 API Key 打通视觉与文本，已验证可用模型 42 个；
豆包视觉模型可**一步到位**（看图直接输出诊断 JSON），链路更短、延迟更低、出错点更少。

## 快速开始

### 后端

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env          # 填入你的火山方舟 API Key
uvicorn main:app --reload --port 8000
```

打开 <http://127.0.0.1:8000/docs> 可在线调试接口（FastAPI 自动生成）。

### 前端

```bash
cd frontend
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。

> 请先启动后端（8000）再启动前端（5173），页面右上角会显示后端连接状态。
> 在页面任意位置按 **Ctrl+V** 即可粘贴错题截图，也支持拖拽或选择文件。

## API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| POST | `/api/diagnose` | 上传错题图片，返回结构化诊断结果 |

诊断返回示例：

```json
{
  "success": true,
  "data": {
    "subject": "高等数学",
    "knowledge_points": ["二阶常系数齐次线性微分方程"],
    "question": "求微分方程 y'' - 3y' + 2y = 0 的通解",
    "correct_answer": "y = C₁e^x + C₂e^(2x)",
    "error_step": 3,
    "error_type": "计算失误",
    "error_analysis": "由 (r-1)(r-2)=0 应得到 r₁=1、r₂=2，学生误写为 -1、-2，属符号计算错误。",
    "solution_steps": ["写出特征方程", "因式分解", "求特征根", "写出通解"]
  }
}
```
